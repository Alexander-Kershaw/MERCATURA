# Project Meridian Architecture

Project Meridian is the Mercatura Group data platform modernisation programme.

The target system will evolve from a simulated operational estate into a
governed Azure Databricks platform supporting batch, CDC and streaming
processing, analytical data products and governed consumption.

## Planned architecture views

Architecture documentation will be developed incrementally as implementation
progresses.

Expected views include:

1. system context
2. source system architecture
3. data platform architecture
4. data lifecycle and medallion architecture
5. deployment and environment architecture
6. security and governance architecture
7. observability architecture
8. data-product and semantic architecture

Documentation will reflect implemented or explicitly targeted architecture
rather than just speculative detail.

## Current state

Phase 0 currently contains only the local engineering foundation.

No Databricks workspace resources or data pipelines have yet been deployed.
